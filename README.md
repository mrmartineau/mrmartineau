### 🛠 What I've been working on recently

- **[ZUI](https://github.com/mrmartineau/zui)** — a CSS-first UI library with design tokens, a layered architecture, and optional React, Astro, Solid & Vue components. No build step required.
- **[Otter](https://github.com/mrmartineau/Otter)** — my self-hosted bookmarking app: links, articles, videos and half-watched TV shows, saved and tagged on your own infrastructure. It now has a [native SwiftUI iOS app](https://zander.wtf/blog/otter-ecosystem) alongside the browser, Raycast and terminal clients.
- **[astro-d1-search](https://github.com/mrmartineau/astro-d1-search)** — full-text site search for Astro backed by Cloudflare D1 and SQLite FTS5. Build-time indexing, an injected `/api/search` endpoint, and no third-party service.
- **[Flora](https://flora.zander.wtf)** — every plant in our house and garden, written up: what it wants, when it flowers, and what needs doing to it before the frost.
- **[Reps](https://reps.zander.wtf)** — a daily JavaScript coding puzzle. Solve one function a day in your browser.
- **[Free Fonts](https://fonts.zander.wtf)** — a curated showcase of free, high-quality typefaces to browse and preview.
- **[Simmer](https://simmer.zander.wtf)** — a recipe management app.
- **[zander.wtf](https://github.com/mrmartineau/zander.wtf)** — my website/portfolio/blog, built with [Astro](https://astro.build/), where I write about things like the CSS features powering ZUI, my zero-to-one tech stack, and evaluating AI agents through side projects.
- **[zed-stack-starter](https://github.com/mrmartineau/zed-stack-starter)** — a modern full-stack React starter: Postgres + better-auth + Drizzle ORM, deployed to Cloudflare Workers.
- **[zed-astro-starter](https://github.com/mrmartineau/zed-astro-starter)** — an opinionated Astro starter with ZUI, ready to deploy to Cloudflare Workers.
- **[My lab](https://lab.zander.wtf/)** — experiments, little tools and things in progress: a drawing app, a keyboard-only navigation demo, a data transformation dojo, a draggable 24-hour clock and more.
- A flurry of small tools and libraries:
  - **[react-status-bar](https://react-status-bar.zander.wtf)** — a portal-based status bar system for React
  - **[Spotify Favourites](https://lab.zander.wtf/spotify-favourites/)** — find your *actual* favourite artists, not just the biggest play counts
  - **[Lang Compare](https://lang-compare.zander.wtf)** — programming language features side-by-side
  - **[Surround for Zed](https://github.com/mrmartineau/zed-surround)** — a Zed extension written in Rust. Never made it into the extension store, so it's a work in progress: clone the repo and install it locally to use it
  - npm packages like [strifx](https://www.npmjs.com/package/@mrmartineau/strifx), [xtractr](https://www.npmjs.com/package/@mrmartineau/xtractr), [url-merge](https://github.com/mrmartineau/url-merge) and [kit](https://github.com/mrmartineau/kit)
  - my various [Raycast extensions](https://github.com/mrmartineau/raycast-extensions)

Many of these were built while putting AI coding agents (Claude Code, Cursor, Amp) through their paces on real work — I wrote about that in [Things I've been building recently while evaluating AI agents](https://zander.wtf/blog/ai-side-projects).
